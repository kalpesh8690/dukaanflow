# DukaanFlow

A mobile-first shop management app for small shops and home businesses.

## Planned stack

- Mobile: Expo React Native + TypeScript
- API: Node.js + Express
- Database: MongoDB + Mongoose
- Authentication: JWT + bcrypt
- Secure token storage: Expo SecureStore
- CI: GitHub Actions

## MVP roadmap

1. Business-owner registration and login
2. Business-scoped product CRUD
3. Orders and customers
4. Staff roles and administration

## Development status

Repository scaffold is being set up. The README describes the intended architecture; features should be treated as incomplete until implemented and tested.
